An entry for make.fun's **Midnight Fridge Roast** — "Write the best roast of a midnight fridge raid".

`main.ts` (Node 22, standard library only) writes one original one-line roast from `roast.txt` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader). The roast takes aim at the fridge's petty midnight rule itself: it locks at midnight like a bouncer who checked your snack history and decided you've had enough.

The entry is one line, 106 characters, UTF-8, not only white space, per the competition's gate. It is entirely original, written for this entry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
